# stripchat.su

Одностраничный сайт на GitHub Pages: трансляции встроены через iframe, вокруг него текст и разметка для поисковиков.

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | Страница: iframe на первом экране, ниже текст, FAQ и JSON-LD |
| `404.html` | Страница ошибки, закрыта от индексации |
| `robots.txt`, `sitemap.xml` | Указания для поисковых роботов |
| `site.webmanifest`, `favicon.*`, `icon-*.png`, `apple-touch-icon.png` | Иконки во вкладке, на телефоне и в выдаче |
| `og-image.png` | Превью ссылки в Telegram, VK, WhatsApp |
| `.nojekyll` | Отключает обработку Jekyll, GitHub Pages отдаёт файлы как есть |
| `CNAME` | Домен для GitHub Pages |

## Что сделать вручную после публикации

1. **HTTPS.** В репозитории: Settings → Pages → включить *Enforce HTTPS*.
2. **Google Search Console** (search.google.com/search-console): добавить ресурс `https://stripchat.su/`, подтвердить через meta-тег (раскомментировать `google-site-verification` в `index.html`) или через DNS, отправить `sitemap.xml`.
3. **Яндекс Вебмастер** (webmaster.yandex.ru): добавить сайт, подтвердить (`yandex-verification`), отправить sitemap, указать регион в разделе «Региональность».
4. **Проверки:**
   - микроразметка: validator.schema.org и «Валидатор микроразметки» в Яндекс Вебмастере;
   - превью ссылок: отправить ссылку себе в Telegram;
   - скорость: pagespeed.web.dev.
5. **Обновлять дату.** При правках текста менять `lastmod` в `sitemap.xml` и `dateModified` в JSON-LD.

## Что ещё даст рост

- **Больше страниц под разные запросы.** Одна страница ранжируется по узкому кругу фраз. Отдельные страницы с уникальным текстом (например, `/russkie/`, `/pary/`, `/s-telefona/`, у каждой свой iframe с нужным `tag=`) расширят охват. Каждую новую страницу добавляйте в `sitemap.xml`.
- **Ссылки на сайт** с тематических площадок и каталогов.
- **Аналитика.** Яндекс Метрика или Google Analytics покажут, по каким запросам приходят люди. Код счётчика вставляется перед `</head>`.
