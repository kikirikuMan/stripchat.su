# stripchat.su

Статический сайт на GitHub Pages: трансляции встроены через iframe, вокруг них тексты и разметка для поисковиков.

## Разделы

| Раздел | Адреса | Куда ведёт |
|---|---|---|
| Зрителям | `/`, `/kategorii/…`, `/gid/…` | iframe с трансляциями, внизу реклама двух разделов ниже |
| Моделям | `/model/…` | реферальная регистрация моделей |
| Партнёрам | `/partner/…` | реферальная регистрация в Stripcash |

Разделы моделей и партнёров не ссылаются друг на друга, сборщик это проверяет.

## Как менять сайт

Страницы не правятся в корне напрямую: они собираются из исходников.

1. Текст страницы: `_src/pages/<путь>.html` (формат описан в [_build/CONTENT_GUIDE.md](_build/CONTENT_GUIDE.md)).
2. Реферальные ссылки, меню, подвалы, параметры iframe: [_build/config.mjs](_build/config.mjs).
3. Оформление: [_build/site.css](_build/site.css).
4. Пересобрать: `npm run build` (Node.js 20.9+ для полного набора инструментов). Команда обновит HTML-файлы, `sitemap.xml` и `assets/site.css`, проверит ссылки, дубли заголовков и разделение разделов. `node _build/build.mjs --stats` покажет объём текста каждой прежней страницы.
5. Закоммитить и запушить и исходники, и собранные файлы.

Новая страница — новый файл в `_src/pages/`; в списки, «Смотрите также» и sitemap она попадёт сама.

Иллюстрации: положите исходники в папку и выполните `python _build/images.py <папка>` (нужен Pillow). Скрипт сделает `img/<имя>.webp` для страницы и обложку `img/og/<имя>.jpg` 1200×630 для соцсетей, а привязку к страницам возьмёт из словаря `IMAGES` в самом скрипте.

Папки на `_` и README GitHub Pages не публикует (см. `_config.yml`).

## Технический справочник на восьми языках

Нейтральные инструкции по камерам, микрофонам, разрешениям браузера и качеству изображения расположены в `/help/` (русский) и `/<язык>/help/` (`en`, `es`, `pt`, `de`, `zh`, `hi`, `ar`). Основной сайт также переведён на эти языки: русские адреса сохранены, другие версии доступны с префиксом языка, например `/en/gid/anonimnost/`.

В справочнике 20 самостоятельных тем: 160 языковых версий статей и восемь оглавлений. Новые темы включают настройку камеры и телефона, фон, зеркальное изображение, свет, разрешение и FPS, работу с источниками, рамкой и кадрированием в OBS. Общая сборка содержит 792 индексируемые страницы: 78 исходных страниц × 8 языков и 168 страниц справочника.

- Содержание и интерфейс: `_src/help/locales/<язык>.json`. Во всех языках одинаковые идентификаторы тем. Китайская версия использует упрощённую письменность (`zh-Hans`), арабская — `dir="rtl"`.
- Шаблоны: `_build/help.mjs`. Справочник подключает общий `assets/site.css`: палитра, шрифты, логотип, ширина контента, карточки, кнопки и подвал совпадают с основным сайтом. `_build/help.css` содержит только дополнения раздела, RTL и адаптацию длинных переводов. Каждая страница имеет собственный canonical, полный взаимный набор hreflang и перевод метаданных. Автоматического перенаправления по языку нет.
- В основном меню всех разделов есть пункт «Камера и звук». Контекстные переходы добавлены в оглавление гидов, материал об оборудовании и страницу «О сайте». Справочник, главная, разделы и служебные страницы связаны в пределах выбранного языка. Переключение языка сохраняет текущую страницу.
- В справочнике отсутствуют сторонние iframe и рекламные переходы. Камера и микрофон проверяются отдельно, только после нажатия кнопки и разрешения браузера. Тест ничего не записывает и не отправляет; устройство освобождается при остановке или скрытии вкладки.
- У теста камеры есть переключатель отражения только локального предпросмотра. Частота кадров из `getSettings()` подписана как заданная; это не измерение доставленных кадров или качества соединения.
- Для каждой из 20 тем создана отдельная схема. Исходники: `_src/help/illustrations/`; опубликованные SVG и PNG: `img/help/`. Пересоздание: `npm run images:help`. Обычная сборка использует готовые изображения и не требует сторонних модулей.
- Разбор Trends: `_src/research/keyword-map.csv`. Wordstat: `_src/research/wordstat-safe-queries.csv` и `_src/research/wordstat-review.md`. Исследование, ограничения и проверки: `_build/SEO_NOTES.md`.

Сборка всех разделов: `node _build/build.mjs`.

Проверка всех сгенерированных страниц: `python _build/check-site.py` (Python 3, без внешних библиотек). Проверяются sitemap, ссылки и якоря, canonical, hreflang, изображения, JSON-LD, доступность страниц с главной и сохранность исходных iframe.

XML-карта — `https://stripchat.su/sitemap.xml`; этот же адрес указан в `robots.txt` и используется для отправки в Google Search Console. В ней 792 канонических URL на восьми языках, взаимные `hreflang` и изображения. Даты `lastmod` отражают изменения содержимого, а не пересборку карты. `priority` и `changefreq` не добавляются: Google их игнорирует. При текущем размере делить карту для соблюдения лимитов не требуется.

Для просмотра XML в браузере сборщик подключает `assets/sitemap.css` из `_build/sitemap.css`: адреса и даты показаны отдельными строками в цветах сайта. Это обычный CSS без JavaScript и XSLT; оформление не меняет XML для поисковых роботов. Проверка сайта дополнительно контролирует структуру XML, пределы 50 000 URL / 50 МБ, корректность дат, адресов и доступность файла оформления.

Зависимости инструментов закреплены в `package-lock.json`: `npm ci --ignore-scripts --no-audit --no-fund`. Нужны Node.js 20.9+, Python 3 и установленный Microsoft Edge. `npm run check:browser` проверяет все темы на всех языках, использует искусственные видео- и аудиоустройства и не обращается к реальной камере или микрофону. `HELP_SCREENSHOT_DIR` задаёт необязательный каталог снимков. Служебные файлы и `node_modules` исключены из публикации GitHub Pages.

Локальный просмотр: после сборки выполните `npm run preview` и откройте `http://127.0.0.1:4173/help/`. Сервер слушает только локальный интерфейс и отдаёт опубликованные страницы и ресурсы, закрывая исходники и зависимости. `HELP_PREVIEW_PORT` позволяет выбрать другой порт. После изменения состава страниц перезапустите сервер. Остановка процесса в терминале — Ctrl+C.

Для промежуточного просмотра во время перевода есть `node _build/build.mjs --preview-ready`: он включает только языки с полными файлами перевода и ставит всем страницам `noindex, nofollow`. Это временная локальная сборка; обычный `npm run build` по-прежнему требует все восемь языков и создаёт полный набор страниц.

Даты изменений прежних материалов берутся из `modified`, затем из истории Git соответствующего исходника, затем из `published`. При отсутствии достоверной даты поле опускается. Дата проверки справочника закреплена в `_build/help.mjs` и должна изменяться только после повторной проверки содержания. Даты публикации автоматически не придумываются.

## Переводы основного сайта

Исходный русский контент — `_src/pages/`. Переводы текстов, метаданных, FAQ и alt — `_src/site-locales/<язык>.json`. Общее меню и подписи — `_build/site-ui.mjs`; маршрутизация переводов — `_build/site-locales.mjs`. HTML формируется при сборке, перевод в браузере посетителя не требуется. Внешний iframe сохранён с исходными параметрами; его внутренний интерфейс обслуживает сторонняя платформа.

Кнопка языка находится в правом верхнем углу общей шапки. `_build/language-switcher.mjs` создаёт раскрывающийся список на `details/summary`, который работает без JavaScript и сохраняет текущую страницу. Небольшой скрипт добавляет закрытие по Escape и нажатию вне списка. На узком экране кнопка показывает код языка; в списке остаются полные названия. Версия скрипта в адресе зависит от его содержимого.

Сборщик проверяет полный набор из 78 страниц на язык, отпечатки исходных текстов и описаний изображений, сохранность тегов и ссылок. Изменения русских исходников требуют актуализации языковых файлов. `sourceDigest` не следует вручную подменять, чтобы пропустить устаревший перевод. Служебные 404 и manifest генерируются для всех языков и не включаются в sitemap. Для общих превью страниц подготовлены 21 языковая карточка в `img/social/`; пересоздание после изменения подписей: `npm run images:social`. Русские оригиналы изображений сохранены.

Для воспроизводимого чернового перевода используется `_build/translate-site.py` и локальный Chrome Translator API через `_build/translate-local-server.cjs`. Запуск моста: `node _build/translate-local-server.cjs`, затем `python _build/translate-site.py --provider local --locales en es pt de zh hi ar --workers 3`. Нужен установленный Chrome с Translator API; языковые модели загружаются при первом использовании. Мост слушает только `127.0.0.1:4186`, не используется опубликованным сайтом и закрывается Ctrl+C. Ранее подготовленные фрагменты имеют отдельную отметку происхождения в JSON. Черновики прошли структурные проверки и выборочную смысловую правку; независимая вычитка носителями всех языков не выполнялась.

`npm run check:fullsite` проверяет основные типы страниц на всех восьми языках, RTL, языковые ссылки, 404, manifest и увеличение текста. Внешние медиа заменяются только внутри тестового браузера. Для смысловой диагностики перевода: `python _build/translate-site-audit.py`; числовые расхождения и термины в отчёте требуют проверки по источнику, а не автоматической замены.

Локальный сервер выбирает язык страницы 404 по пути. На боевом хостинге эта маршрутизация зависит от его конфигурации; наличие `/en/404.html` само по себе не меняет обработку неизвестных URL на GitHub Pages.

## Что сделать вручную после публикации

1. **HTTPS.** Settings → Pages → *Enforce HTTPS*.
2. **Google Search Console** и **Яндекс Вебмастер**: добавить сайт, подтвердить права (метатеги закомментированы в `<head>` сборщика, коды вставляются в [_build/build.mjs](_build/build.mjs)), отправить `https://stripchat.su/sitemap.xml`.
3. **Проверки:** validator.schema.org, превью ссылки в Telegram, pagespeed.web.dev.
4. **Аналитика:** Яндекс Метрика или Google Analytics, код добавляется в шаблон `<head>` в сборщике.
