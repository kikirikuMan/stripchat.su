隐私政策

一般规定

Stripchat.su 是静态网站。本站没有表单、注册或评论功能，不收集您的个人数据，也不设置自己的 Cookie。

网站页面中使用的第三方服务可能处理数据，包括托管服务、直播组件，以及启用时的网站分析系统。下文说明涉及哪些数据，以及在哪里查看相关信息。

托管

本站托管于 GitHub Pages。与任何网络服务器一样，托管服务会接收请求的技术数据，包括 IP 地址、浏览器类型、页面地址和访问时间。这些数据由 GitHub 按其隐私政策处理，网站所有者无法访问服务器日志。

直播组件

直播区域从 Stripchat 合作伙伴计划的服务器加载，其中适用平台自身的规则。平台可能设置自己的 Cookie、记录通过合作伙伴链接产生的访问，并处理您注册或付款时输入的数据。这些数据由平台接收，Stripchat.su 无法获取。

如果您在平台上注册或购买代币，请阅读其隐私政策和使用条款。

合作伙伴链接

观众、主播及合作伙伴的注册链接包含本站合作伙伴账号的标识，平台据此识别访问来自本站。网站所有者不会因此获得个人数据，合作伙伴统计仅显示去标识化的注册和购买信息。

网站分析

如果本站启用网站分析系统，例如 Yandex Metrica 或 Google Analytics，这些系统会收集去标识化的访问统计，包括打开的页面、停留时间和使用的设备。数据用于改进网站，不用于识别个人身份。您可通过浏览器设置或跟踪器拦截工具关闭相关收集。

您可以做什么

  • 在浏览器设置中清除 cookie 和站点数据。
  • 阻止第三方 Cookie，但这可能影响直播组件的正常运行。
  • 使用无痕模式访问，以免访问记录保留在浏览器历史中。

如何在平台上保护隐私，请参阅 匿名使用指南.

政策变更中描述

如果网站增加处理数据的新服务，本页面会相应更新。有关网站的一般规定信息，请参阅 “关于网站”.
