在 GitHub Pages 免费搭建合作伙伴网站

为什么静态网站和 GitHub 页面

如果您刚刚开始与您的合作伙伴合作，GitHub 页面上的网站会更便宜。 托管是免费的，服务器不需要管理，页面加载速度很快，因为这些都是普通的HTML文件。 该站点的排列方式相同：脚本将文本、菜单和元标记收集到静态页面中，并且通过 iFrame 的 iFrame 将直播从 StripCash 推广工具加载。

静态网站没有数据库、个人账号和评论，他本人什么都不知道。 对于附属项目，这更像是一个加分项。 那里没有什么可以打破和破解的，所有的注意力都集中在有用的文本上。 您可以阅读有关 合作伙伴工具的文章中的其他格式的促销信息.

在启动之前，请阅读 GitHub 的有效使用规则。 它们限制了坦率的内容，因此它们只在这样的网站上放置文本，并且广播以安全模式嵌入，没有坦率的预览。 不要忘记你国家的法律。

步骤 1. 存储库和出版物

  1. 在 GitHub 上注册一个帐户并创建一个公共存储库。
  2. 将 index.html 文件放在根目录中。 对于每个下一页，在 index.html 中启动一个单独的文件夹，然后地址将变得整洁，例如 /razdel/stranica/。
  3. 打开设置 → 页面并选择源分支（通常为主）和根文件夹。
  4. 一两分钟后，网站将在用户名.github.io/repository name 的地址打开。

当有十多个页面时，开头和每只手的菜单都很无聊。 将文本单独存储并使用静态站点的小脚本或生成器组装更方便。 输出仍将获得一组 HTML 文件。

步骤 2. 自己的域和 CNAME

在 Github.io 子域上，该站点正在运行，但合作伙伴项目最好有自己的域。 它更容易记住，它与帐户的名称无关。

  1. 从任何注册商处购买域名。 如果您不了解风险，最好不要在名称中使用他人的商标。
  2. 在 Settings → Pages 中，将域名填入 Custom domain 字段。GitHub 会在仓库中创建包含该域名的 CNAME 文件，不要删除它。
  3. 在注册商处配置 DNS。 根域 A 记录到 GitHub 页面的 IP 地址 从 GitHub 文档中，对于 www ，将 cname 条目设置为 username.github.io。
  4. 等待 DNS 更新。 这通常需要几分钟到一天的时间。

步骤 3. HTTPS

一旦 DNS 工作，GitHub 将发出证书本身，并在设置 → 页面中显示强制 HTTPS 复选框。 打开它。 如果没有 HTTPS，浏览器会将网站标记为不安全，并且内置的广播和表单可能无法加载。 非活动复选标记表示 DNS 尚未更新或配置有错误。

步骤 4：内置广播和链接

在 StripCash 机柜中生成带有广播的 StripCash 小部件代码。 通常，这是一个 iframe 标记，它已经缝制了您的合作伙伴 ID，并且类别和显示模式由参数设置。 将代码粘贴到广播应该去的地方的 HTML 页面中。

  • 设置 iframe 100% 宽度和合适的高度，然后检查手机上的外观。
  • 在类别页面上，打开相应的广播过滤器，使内容与主题相匹配。
  • 外部推荐链接设置了 REL 属性，并设置了赞助值。 因此，您诚实地通知搜索引擎该链接是附属的。

步骤 5. 基本 SEO

标题和说明

每一页都需要自己的标题，最多 60-65 个字符，开头有一个关键短语，以及自己对 120-160 个字符的描述。 不同页面上的相同标题被视为重复。

唯一文本

搜索引擎只有 iframe 的页面为空。 写出回答真正问题的文本：如何使用服务、类别有何不同、如何维护隐私。 通过更改关键字不可能将一篇文章相乘，因此该网站将很快被过滤器下方。 分析中更详细地描述了这个陷阱 新手错误.

sitemap 和 robots.txt

创建一个包含所有页面列表和更新日期列表的 sitemap.xml 文件，并指定他的路径 机器人.txt。 生成器或汇编脚本可以自动完成。

搜索控制台和 Yandex 网站管理员

将网站添加到 Google Search Console 和 Yandex 网站管理员。 最简单的方法是确认主页头部的元标记或 DNS 中的 TXT 记录。 然后发送站点地图并按照索引和错误报告进行操作。

步骤 6. 年龄标记

介绍成人服务的网站应明确说明内容性质。在每个页面的 head 部分添加值为 adult 的 rating 元标签，安全搜索和家长控制会参考它。在页脚或首屏放置 18+ 警告，并说明本站不是 Stripchat 官方网站。这有助于保护未成年人，并降低被搜索引擎处罚的风险。

常见问题

github页面上的网站要多少钱？

对于公共存储库，GitHub 页面托管是免费的。 如果需要，您只需要为自己的域名付费。

我可以将我的域名连接到 GitHub 页面吗？

可能。 域适合页面设置，CNAME 文件出现在存储库中，注册器配置指向 GitHub 服务器的 DNS 记录。

该网站会有https吗？

意志。 一旦 DNS 记录工作，GitHub 将自己颁发证书，并且在设置中包含强制 HTTPS。

GitHub 允许成人主题网站吗？

GitHub 对 GitHub 的可接受使用限制了明确的内容。 在启动前阅读它们，并在安全模式下仅发布文本和广播，无需明确预览。
