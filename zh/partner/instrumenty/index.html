Stripcash 合作伙伴推广工具

为什么合作伙伴需要多种工具？

所有工具 Stripcash 解决一个问题：让您的访问者成为 Stripchat 的用户，系统会为您写下来。 对于频道中的帖子，一种格式是方便的，对于具有另一个类别的网站，另一种格式对于广告活动。 以下是该计划中的主要促销类型，以及每个促销类型。

一组特定的格式，它们的设置和代码在个人帐户中发布。 名称和接口随时间变化，所以这里描述了操作原理，不绑定按钮。 工具如何与支付模型相关联，请阅读文章 如何在 Stripcash 中赚钱.

推荐链接

每个人都从他们开始。 您的标识符已缝在链接中，传递给您的访问者已分配给您。 通常您可以选择它的通向位置：到主页、注册页面或特定类别的广播。

很容易弄乱链接，而且通常是琐碎的事情。 地址缩写和额外重定向有时会切断参数，过渡不计算在内。 如果您需要一个简短的地址，请进行测试过渡并在统计数据中进行检查。 您也不应该将链接伪装为其他东西，访问者必须了解将获得网络摄像头服务的内容。

您可以在电报频道的描述中放置指向网站按钮的链接，在审阅文本中。 例如，在这个网站上，所有注册按钮都会导致定期的附属链接。 将访客送到他将立即看到承诺的地方。 指向所需类别的链接几乎总是比一般主要类别的效果更好。

横幅

不同尺寸的现成图片，内置推荐链接。 它们将在有广告空间的网站和在成人网络中购买时很有用。 插入横幅就像炮击梨一样简单，但是，横幅盲目并没有消失：游客习惯于将眼睛滑过广告单元。 最重要的是，横幅与文本协同工作，并不单独表现良好。

在放置之前，请确保所选的横幅符合您网站的规则。 许多网站和网络仅接受没有显式图像的版本。

嵌入式广播（iFrame 和广告素材）

最可视化的格式。 在您的页面上有自行更新的直播广播，访问者看到正在发生的事情，并切换到服务，已经选择了广播。 这就是本网站主页的排列方式，其上的广播是通过节目小部件构建的。

  • 过滤器

    您通常可以设置广播类别以显示与页面主题匹配的内容。

  • 外观

    尺寸和设计是可定制的，因此可以将小部件输入到网站设计中。

  • 安全模式

    如果设置中有一个没有明确预览的选项，它将在有限制的区域派上用场。

小部件在类别页面和主页上看起来不错。 同时，它不提供唯一的内容，搜索引擎对一个iframe的页面不感兴趣，所以添加有用的文本。 一步一步的例子在指南 中如何在 GitHub 页面上制作网站.

着陆页和着陆页

程序本身准备和锐化的促销页面 注册。 它们主要由媒体买家使用：广告网络中的广告带有您的标识符，登陆页面将访问者带入创建帐户的访问者。 尝试几个选项，在相同的流量上，着陆有时在转换方面存在明显不同。

诚实地测试：一个登陆页面与另一个在同一来源、地理和设备上的登陆页面，每个都有自己的标签。 比较不同星期和不同站点收集的结果是没有用的，因为差异会给流量带来流量，而页面与之无关。

White label

一个完整的网络摄像头网站，您的品牌和基于域的平台。 用户在您的网站上注册和购买，而广播、支付和支持仍保留在该服务中。 事实上，这是一个独立的项目，有自己的优势和责任，你不能称它为链接。 有关更多格式，请参阅文章 什么是白标.

统计和子 ID

统计显示过渡、注册、购买和应计。 如果您将标签（sub-id）添加到链接，它会更有用。 这是一个小项目的标记可能是什么样子的。

API

对于那些与代码是朋友的人，程序打开程序访问数据的访问权限。 一般来说，通过 API，您可以接收广播列表并以您自己的方式在网站上安排它们，以及在您自己的分析系统中获取统计信息。 当没有足够的标准小部件时，这会有所帮助，例如，您需要自己的目录布局或自动报告。 文档和访问密钥在办公室。 如果您不编写代码，请从链接和小部件开始，大多数项目都有足够的边距。

常见问题

哪个工具 Stripcash 最简单？

定期推荐链接。 它放在文本、按钮或通道的描述中，没有设置任何内容。

是否可以在您的网站上嵌入广播？

可能。 该节目具有通过 iframe 插入的直播节目的小部件，代码和设置在合作伙伴的办公室中。

为什么需要子 ID？

使用标签，统计信息按来源、页面和广告系列共享。 没有它们，仍然可以猜测究竟是什么带来了注册。

我需要程序员使用 API 吗？

API需要基本的开发技能。 链接、横幅和小部件没有程序员：将完成的代码插入页面就足够了。
