用Iriun把手机连接为电脑摄像头

Iriun把手机摄像头提供给电脑上的视频应用。排查时应分清手机是否在拍摄、电脑端是否收到画面，以及目标应用是否选中了Iriun输入。

  2. 按连接链逐段确认
  3. 画面没有到达哪一环
  4. 比较效果并结束连接

从官方入口核对兼容性

Iriun官网提供电脑端软件，并说明需要手机端应用配合。下载前核对你的操作系统和当前支持要求；安装包版本与系统要求会变化，不宜照搬旧教程中的版本号。手机应用也应从官方入口指向的应用商店获取。

先用手机自带相机确认镜头能正常工作，再把手机固定在稳定支架上。检查电量和散热空间，避免长时间使用时被手掌、保护壳支架或其他物品遮挡镜头。

按连接链逐段确认

先让Iriun电脑端出现手机画面，然后再检查视频应用。这一步能避免把手机与电脑之间的问题误认为浏览器权限问题。

  1. 按当前官方说明安装相应电脑端和手机端应用。
  2. 允许手机端使用摄像头，并启动两端程序。
  3. 无线连接失败时，核对两端是否处于可以相互通信的本地网络；访客网络可能隔离设备。
  4. 电脑端有画面后，在视频应用中选择Iriun对应的摄像头输入，再进行预览。

画面没有到达哪一环

手机有画面、电脑端没有画面时，重点检查连接状态、网络隔离和应用是否仍在运行。可以查看系统防火墙是否阻止了该程序，但不要为了测试直接长期关闭防火墙。公司或学校网络由管理员管理时，应先询问其限制。

电脑端有画面、浏览器没有画面时，先检查浏览器选中的设备。安装后一直打开的应用可能需要重新启动，才能重新读取设备列表。若画面冻结，分别观察手机预览和电脑预览，记录从哪一环开始停止更新。

比较效果并结束连接

保持同一位置和光线，比较手机摄像头与原有摄像头的取景、稳定性和声音来源。手机画面更清楚不代表通话延迟一定更低，也不代表目标应用会采用同样的分辨率。音频仍需单独检查。

本页摄像头测试不会上传视频，但Iriun本身是另一个软件，应另外阅读它的权限与隐私说明。用完后停止网页测试并退出不再使用的手机端、电脑端应用，再确认摄像头访问已结束。
