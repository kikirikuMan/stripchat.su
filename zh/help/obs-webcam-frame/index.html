如何在 OBS 中给摄像头添加边框

摄像头边框通常是一张位于摄像头来源上方的独立图片。中间窗口必须透明，才能看到下面的视频。先确认场景中的摄像头正常，再添加和对齐装饰。

本页目录

  1. 导入前检查图片
  2. 把边框放到摄像头上方
  3. 对齐窗口但不要拉伸人脸
  4. 每次只检查一层

导入前检查图片

使用自己制作或获得使用许可的边框。PNG 可以包含透明信息，但扩展名本身不能保证透明。用能显示 Alpha 通道的编辑器检查中间窗口。

画在图片中的棋盘格不等于透明。如果格子本身是像素，它们会像纯色一样遮住摄像头。保留原始文件，方便修正开口而不必重建场景。

把边框放到摄像头上方

  1. 在已有可用摄像头的同一 OBS 场景中添加“图像”来源，选择边框文件。
  2. 在来源列表中把图像放在摄像头上面，让边框绘制在视频之上。
  3. 调整边框的位置和大小，再调整下面的摄像头，使其匹配透明窗口。
  4. 精确定位时使用“编辑变换”。完成后锁定来源，减少编辑其他内容时误拖动的机会。

对齐窗口但不要拉伸人脸

比较开口与摄像头画面的形状。如果比例不同，仅缩放可能留下空隙或造成变形。选择合适的边框，或有计划地裁掉部分图像，同时保持主体自然比例。

在镜头前正常活动，检查头部与手部周围的边缘。只适合静止人脸的布局可能截掉手势。按实际显示大小检查，复杂边框可能让小摄像头窗口显得拥挤。

每次只检查一层

如果整幅画面消失，先临时隐藏边框。摄像头恢复说明问题可能在图片不透明、开口或位置；如果只有边框不见，检查其可见性及与摄像头的上下顺序。

把图片保存在稳定的本地目录中，因为图像来源引用的是这个路径。移动素材后，重新打开场景检查是否缺图，再使用保存的布局。
