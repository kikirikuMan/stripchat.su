摄像头被其他应用占用时如何排查

摄像头可能在一个应用中正常工作，却无法在另一个应用中打开。排查时每次只保留一个使用摄像头的程序。“无法读取设备”是一条线索，并不能证明一定有其他程序占用。

关闭应用前先记录现象

记下哪个应用正常、哪个失败，以及完整的错误提示。权限被拒绝、找不到摄像头和已列出的设备无法打开，需要分别检查。不要因为某个应用提示忙碌，就同时更改多处权限。

如果正在参加会议，请保存工作并退出后再测试。关闭摄像头应用会中断该应用的视频。

每次只让一个应用使用摄像头

重试成功能帮助找到可用的处理方式，但不能由此认定所有摄像头或操作系统都禁止多个应用同时访问。

  1. 停止其他浏览器标签页、会议软件和摄像头设置工具中的预览。
  2. 正常退出这些应用，再检查通知区域或菜单栏，确认窗口关闭后是否仍有工具在后台运行。
  3. 重新加载出错的页面，尝试启动一次摄像头。成功后先停止测试，再打开另一个应用。
  4. 逐个重新打开其他程序，每次重复相同检查，观察冲突何时再次出现。

其他应用关闭后仍然报错

单独运行系统相机应用，然后关闭它，再测试浏览器。如果只有浏览器失败，检查所选摄像头及权限。如果两边都失败，先检查 USB 连接和物理开关，再考虑重新安装软件。

浏览器的 NotReadableError 也可能与操作系统或硬件问题有关。保留完整提示，不要把错误名称当成已经确认的原因。

获得可重复的结果

如果仍不清楚哪个程序占用设备，保存工作后重启电脑，只打开目标应用。将这次干净启动的结果与之前比较。

在单位管理的电脑上，向技术支持提供摄像头型号、出错应用、错误信息和单应用测试结果。不要随意关闭安全控制，也不要反复终止不认识的系统进程。
