A free affiliate website on GitHub Pages

Why is the static site and GitHub Pages

the site on GitHub Pages is cheaper if you are just starting to work with your partner. Hosting is free, the server does not need to be administered, and the pages are loaded quickly, because these are ordinary HTML files. This site is arranged in the same way: the script collects texts, menus and meta tags into static pages, and live broadcasts are loaded through the iframe from the StripCash Promoting Tools.

The static site does not have a database, personal accounts and comments, he himself does not know anything. For an affiliate project, this is more of a plus. There is nothing to break and hack there, and all the attention goes to the useful text. You can read about other formats of promo in the article about partner tools.

Before launching, read the rules for valid use of GitHub. They limit frank content, so they place only text on such a site, and broadcasts are embedded in safe mode without frank previews. Don't forget about the laws of your country.

Step 1. Repository and publication

  1. Register an account on GitHub and create a public repository.
  2. Put the index.html file in the root. For each next page, start a separate folder with index.html inside, then the addresses will turn out to be neat, like /razdel/stranica/.
  3. Open Settings → Pages and select the source branch (usually Main) and root folder.
  4. After a minute or two, the site will open at the address of the user name.github.io/repository name.

When there are more than a dozen pages, prescribing the header and the menu in each hand is boring. It is more convenient to store texts separately and assemble the site with a small script or generator of static sites. The output will still get a set of HTML files.

Step 2. Own domain and CNAME

on the GitHub.io subdomain, the site is running, but it is better for a partner project to have its own domain. It is easier to remember, and it is not tied to the name of the account.

  1. Buy a domain from any registrar. It is better not to use other people's trademarks in the name if you do not understand the risks.
  2. In Settings → Pages, enter the domain in the Custom Domain field. GitHub will create a cname file with this domain in the repository, it cannot be deleted.
  3. Configure DNS at the registrar. Root domain A-records to GitHub Pages IP addresses from GitHub documentation, and for www, set a CNAME entry to the username.github.io.
  4. Wait for the DNS update. This usually takes from a few minutes to a day.

Step 3. HTTPS

As soon as the DNS works, GitHub will issue the certificate itself, and the Enforce HTTPS checkbox appears in Settings → Pages. Turn it on. Without HTTPS, browsers mark the site as insecure, and built-in broadcasts and forms may not load. The inactive check mark means that the DNS has not yet been updated or the entries are configured with an error.

Step 4: Built-in Broadcasts and Links

Generate the StripCash widget code with broadcasts in the StripCash cabinet. As a rule, this is an iframe tag, which already has your partner ID sewn up, and the category and display mode are set by parameters. Paste the code into the HTML pages in the place where the broadcasts should go.

  • Set iframe 100% width and suitable height, then check how it looks on the phone.
  • On the categories pages, turn on the corresponding broadcast filter so that the content matches the theme.
  • External referral links set the REL attribute with the Sponsored value. So you honestly inform the search engines that the link is affiliate.

Step 5. Basic SEO

Title and Description

Each page needs its own title up to 60–65 characters with a key phrase at the beginning and its own description of 120–160 characters. The same title on different pages is taken as duplicates.

Unique text

The page where there is only iframe is empty for the search engine. Write texts that answer real questions: how to use the service, how the categories differ, how to maintain privacy. It is impossible to multiply one article by changing the keyword, so the site will quickly be under the filter. This trap is described in more detail in the analysis Newbie errors.

Sitemap and robots.txt

Create a sitemap.xml file with a list of all pages and update dates and specify the path to him in robots.txt. The generator or assembly script can do it automatically.

Search Console and Yandex Webmaster

Add the site to Google Search Console and Yandex Webmaster. The easiest way is to confirm the meta tag in the HEAD of the main page or a TXT record in the DNS. Then send sitemap and follow the indexing and error reports.

Step 6. Age labeling

A website about an adult service must clearly identify its subject. Add a rating meta tag with the value adult to the head section of every page; SafeSearch and parental filters use it. Place an 18+ warning in the footer or at the top of the page, and explain that the site is not an official Stripchat resource. This helps protect minors and reduces the risk of search engine penalties.

What's next

After launch, the work is just starting. In the first weeks, search engines look closely at the site, and there will be almost no traffic. Add useful pages regularly, fix bugs from webmaster reports and see statistics in the office Stripcash with labels breakdown. If you want to speed up, connect others Traffic sources and follow their rules.

Frequently asked questions

How much does a site cost on GitHub Pages?

For public repositories, GitHub Pages hosting is free. You will only have to pay for your own domain if you need it.

Can I connect my domain to GitHub Pages?

possible. The domain fits in the Pages settings, the CNAME file appears in the repository, and the registrar configures DNS records leading to GitHub servers.

Will the site have https?

will. As soon as DNS records work, GitHub will issue the certificate itself, and it remains to include forced HTTPS in the settings.

Does GitHub allow 18+ sites?

GitHub's acceptable use of GitHub limits explicit content. Read them before launch and post only text and broadcasts in safe mode, without explicit previews.
