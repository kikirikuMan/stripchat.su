Turn your webcam on and stop it safely

A shutter, a device setting and a site's permission switch do different jobs. Use the control that matches your aim: show a picture now, stop the current session or prevent a particular app from using the camera later.

On this page

  1. Check the physical control
  2. Start one deliberate session
  3. Stop the session and verify
  4. Decide what should remain permitted

Check the physical control

Some cameras have a sliding cover; some laptops have a camera key or hardware switch. A cover may only block the lens, while a switch may disconnect the device. Check your device's manual rather than assuming the indicator light has the same meaning on every model.

Remove a cover only when you are ready to check the picture. An uncovered lens does not by itself grant a website permission or start this site's test.

Start one deliberate session

  1. Confirm that the operating system permits the intended app to use the camera.
  2. Open the camera test and press Start camera. Respond to the browser prompt for this site.
  3. Move a hand in view to confirm that the picture is live. Check the selected source if the image comes from another camera.

Stop the session and verify

Press Stop in this site's test. Its preview clears and it releases the media tracks. This test also stops when the tab is hidden. Another app can still be using the same or a different camera, so inspect other open previews if an indicator remains on.

In another application, use that application's camera controls and check its documented behavior. Closing a window may leave an app running in the background. Save work before fully quitting it.

Decide what should remain permitted

Revoking a site's camera permission controls future requests from that site; it is different from disabling the entire device. Use the browser's site settings for a single website and operating-system privacy settings for application access.

If you disable the camera system-wide, note how to re-enable it before the next call. On a managed computer, settings may be controlled by an administrator. Do not bypass those controls; request the access needed for the specific application.

Privacy

The test starts only when you press a start button and the browser permits access. Video and audio are processed locally in your browser; this tool does not record or upload them. The hosting service still receives normal HTTP requests when you load this page.
