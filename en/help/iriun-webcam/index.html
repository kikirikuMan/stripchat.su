Set up Iriun Webcam on a phone and computer

Iriun adds another link to a camera setup: the phone must send a picture to the desktop software before a calling app can use that source. Check those stages separately when the final preview is blank.

On this page

  1. Install the matching components
  2. Make the first connection
  3. Find where the picture stops
  4. Check sound and end the session

Install the matching components

Use the desktop downloads on iriun.com and the mobile app published by Iriun. Check the stated system requirements before installing; requirements and available features can differ between platforms.

Keep the phone and computer where you can see both screens during the first test. Put the phone on a stable support so handling it does not obscure whether the video is updating.

Make the first connection

The Android publisher's instructions call for starting the phone app and the desktop server, then choosing Iriun as the video source in the receiving app. Begin with a simple local network setup.

  1. Open Iriun on the phone and allow the camera access it requests.
  2. Start the Iriun desktop software and check whether it receives a moving picture.
  3. Only after that works, open the calling app and choose Iriun Webcam in its camera settings.

Find where the picture stops

If the phone preview itself fails, investigate the phone's camera permission first. If the phone shows video but the desktop does not, check their network connection and the desktop program's connection state.

For a Wi-Fi comparison, place both devices on the same trusted home network rather than separate guest networks. Network isolation or a VPN configuration is a possible area to investigate, not a reason to disable every security control.

If the desktop preview works but the calling app is blank, reselect the Iriun source and restart that app. Reinstalling the phone app is unlikely to be the most informative first comparison.

Check sound and end the session

Choose the microphone separately in the receiving app; do not infer working sound from a moving picture. Make a short input-level test before the call.

If video freezes later, note which preview stops first and what changed on the phone at that moment. After use, stop the receiving test and close the Iriun session. This page's local-test privacy description does not describe Iriun's own software or policies.

Privacy

The test starts only when you press a start button and the browser permits access. Video and audio are processed locally in your browser; this tool does not record or upload them. The hosting service still receives normal HTTP requests when you load this page.
