Find the cause of a black webcam screen

A black preview can appear even when a camera is listed. Before replacing hardware, distinguish a covered lens, an inactive video source and a stream that never started. Each leads to a different next check.

On this page

  1. Describe what is actually visible
  2. Check the lens and selected source
  3. Compare two apps, one at a time
  4. Isolate the connection path
  5. Prepare a useful support report

Describe what is actually visible

Note whether the preview is uniformly black, shows a dim outline, displays an error, or holds an old frame. Move a hand in view to test whether the picture is updating.

Write down the camera name shown in the app and the exact error text. An indicator light alone does not establish that the intended scene is reaching this particular preview.

Check the lens and selected source

Open any physical cover and inspect whether the lens is obstructed. If you can see a faint image, try a better-lit position and compare again.

Confirm the selected camera. A laptop's internal camera, USB webcam and virtual camera can appear in the same list. A virtual source may be present while its producing application is closed.

  1. Select the physical camera you want to test.
  2. Stop and restart the preview after changing the selection.
  3. Check that a movement in front of that lens appears on screen.

Compare two apps, one at a time

Close the current preview and open the computer's camera application. Then close that application and retry the browser test. Keeping only one test active makes the comparison easier to interpret.

If the camera works in one app, check the failing app's source and permissions. If every app fails, continue with the device connection and operating system checks. This comparison narrows the search; it does not identify a failed component with certainty.

Isolate the connection path

For an external camera, reconnect it and compare a direct USB connection with the current dock or hub setup. Change one part at a time so you can say which connection worked.

For a built-in camera, check the laptop's documented privacy key or switch. After a system update, consult the computer manufacturer's camera guidance before making driver changes.

Prepare a useful support report

If the picture stays black, record the device model, system version, selected camera name and the two-app comparison. Include whether the fault began after a move, update or new adapter.

These details help distinguish a repeatable setup problem from an intermittent fault. Do not keep reinstalling unrelated drivers after each unsuccessful preview.
