Crop and position a webcam picture in OBS

Cropping removes unwanted edges; scaling changes the displayed size. If you want a narrower camera panel, crop first and resize the remaining picture proportionally so faces and objects keep their shape.

On this page

  1. Define the frame you need
  2. Crop with a reversible transform
  3. Check what the crop changed
  4. Keep framing separate from privacy

Define the frame you need

Decide which part of the picture must remain visible: your head, hands or an object on the desk. Leave room for normal movement. A frame that fits only while you sit perfectly still will clip useful content during a call.

Keep a copy of the scene layout or note the transform values before editing. A camera can look stretched even when it is working correctly; that is a layout issue rather than a sensor fault.

Crop with a reversible transform

  1. Select the camera source in OBS and open Edit Transform. Adjust the crop values for the edges you want to trim.
  2. Alternatively, hold Alt on Windows or Option on macOS while dragging the source's bounding-box handles, as described in OBS documentation.
  3. Resize and position the cropped result without deliberately stretching it to a different aspect ratio. Use the transform controls when precise placement matters.

Check what the crop changed

Move your hands toward the edges and lean slightly in each direction. If an important area disappears, reduce the crop or reposition the camera. Check a round object in the picture; an obvious oval can reveal unwanted stretching.

Cropping does not create more camera detail. Enlarging a small cropped region can make it look softer. Before increasing sharpening, compare a less aggressive crop at the same displayed size.

Keep framing separate from privacy

Check every scene that uses the camera. Cropping one source layout does not guarantee every other scene or app uses that crop. Remove sensitive objects from the room when their accidental appearance would matter.

When using a decorative overlay, place it above the camera and inspect its transparent opening. The frame guide covers that layer separately. Save the layout only after checking normal movement and the intended output dimensions.
