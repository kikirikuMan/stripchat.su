Restore camera and microphone permissions

Camera access can be blocked at more than one level. A website permission, an operating system setting and a physical privacy switch serve different purposes. Work through the level that matches the message on screen.

On this page

  1. Identify the blocked permission
  2. Review this website in the browser
  3. Check access granted to the browser
  4. Retry without changing everything
  5. Remove access when it is no longer needed

Identify the blocked permission

Start the test once and read the request. Camera and microphone access are separate, so a microphone prompt is not a substitute for camera permission.

Check that the page address is the one you intended to open. Browser camera access needs a supported secure context; on this public site, use the HTTPS address. A managed work computer may also restrict settings through its administrator.

Review this website in the browser

In Chrome, open the site's settings from the control beside its address and review Camera or Microphone. Change only the permission needed for this site, then reload and retry.

In Firefox, the camera and microphone lists are under Settings, Privacy & Security, Permissions. Clear or update the saved decision for the relevant site. If prompts were blocked globally, that setting can explain why no new request appears.

Check access granted to the browser

On Windows 11, camera settings are under Settings, Privacy & security, Camera. Review device access and the option for desktop apps, which includes browsers.

On macOS, check System Settings, Privacy & Security, Camera for the browser. Safari also has website-specific camera controls in Safari Settings, Websites. Menu labels can vary with the system language and version.

Retry without changing everything

Close the failed preview before testing again. If the browser asks for a restart after an operating system change, follow that request and return to the same page.

When permission is allowed but the camera is still missing, move to the connection check. Repeatedly granting access cannot reconnect an unplugged camera or choose the intended lens.

Remove access when it is no longer needed

Stop the test and review the site's saved permission if you want it to ask again next time. A remembered permission and an active camera session are different states.

Avoid clearing all browsing data merely to fix one camera permission: first correct the specific site's setting. If a setting is locked by your organization, give the administrator the exact error and site address.

Privacy

The test starts only when you press a start button and the browser permits access. Video and audio are processed locally in your browser; this tool does not record or upload them. The hosting service still receives normal HTTP requests when you load this page.
