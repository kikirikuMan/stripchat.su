Fix a black webcam picture in OBS

First find out whether OBS is receiving no camera image or whether the scene is hiding an image it already receives. Those cases need different checks and should not lead straight to reinstalling drivers.

On this page

  1. Compare the source preview and the scene
  2. Try a clean scene
  3. Release the camera elsewhere
  4. Restore a known working configuration

Compare the source preview and the scene

Open the camera source's properties and look at its preview. If the picture appears there but not in the scene, inspect visibility, source order and transforms. A fully opaque image source above the camera can cover it.

If the source preview is also blank, verify the selected device. A similarly named virtual camera is not necessarily the USB camera in front of you. Note any error message before changing settings.

Try a clean scene

  1. Create a temporary scene with only the existing camera source added to it. Keep the original scene intact.
  2. Check the source's visibility and reset its transform in the temporary scene if it lies outside the canvas.
  3. Use a default supported capture mode first. If you previously forced a custom resolution or frame rate, remove that extra variable and retry.

Release the camera elsewhere

Close browser tests and camera previews in other apps, then retry OBS. To compare with the system camera app, release the OBS camera first and run only one test at a time. A busy device is one possible cause, not a conclusion you can draw from every black frame.

If the system app also fails, check the cable, physical cover and operating-system permissions. If only OBS fails, record the source settings and application version for a focused support request.

Restore a known working configuration

Once the temporary scene shows a moving picture, return to the original scene and reintroduce layers one at a time. Stop when the source disappears; the last change is a useful clue.

Avoid downloading random driver packages or plugins as a first step. Keep the temporary scene until the result survives closing and reopening OBS. This procedure tests local capture only; it does not diagnose a remote service or internet connection.
