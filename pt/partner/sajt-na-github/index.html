Site de afiliado gratuito no GitHub Pages

Por que o site estático e as páginas do GitHub

O site no GitHub Pages é mais barato se você está apenas começando a trabalhar com seu parceiro. A hospedagem é gratuita, o servidor não precisa ser administrado e as páginas são carregadas rapidamente, porque são arquivos HTML comuns. Este site é organizado da mesma maneira: o script coleta textos, menus e metatags em páginas estáticas, e as transmissões ao vivo são carregadas pelo iframe das ferramentas de promoção do Stripcash.

O site estático não possui banco de dados, contas pessoais e comentários, ele mesmo não sabe de nada. Para um projeto de afiliado, isso é mais uma vantagem. Não há nada para quebrar e hackear, e toda a atenção vai para o texto útil. Você pode ler sobre outros formatos de promoção no artigo sobre Ferramentas para parceiros.

Antes de iniciar, leia as regras para o uso válido do GitHub. Eles limitam o conteúdo franco, então apenas colocam texto em tal site, e as transmissões são incorporadas no modo de segurança sem prévias francas. Não se esqueça das leis do seu país.

Etapa 1. Repositório e Publicação

  1. Registre uma conta no GitHub e crie um repositório público.
  2. Coloque o arquivo index.html na raiz. Para cada página seguinte, inicie uma pasta separada com index.html dentro, então os endereços ficarão legais, como /razdel/stranica/.
  3. Abra Configurações → Páginas e selecione a ramificação de origem (geralmente principal) e a pasta raiz.
  4. Após um ou dois minutos, o site será aberto no endereço do nome de usuário.github.io/repositório nome.

Quando há mais de uma dúzia de páginas, prescrever o cabeçalho e o menu de cada mão é chato. É mais conveniente armazenar textos separadamente e montar o site com um pequeno script ou gerador de sites estáticos. A saída ainda receberá um conjunto de arquivos HTML.

Etapa 2. próprio domínio e CNAME

O site funciona no subdomínio GitHub.io, mas é melhor para um projeto de parceiro ter seu próprio domínio. É mais fácil de lembrar e não está vinculado ao nome da conta.

  1. Compre um domínio de qualquer registrador. É melhor não usar as marcas registradas de outras pessoas no nome se você não entender os riscos.
  2. Em Configurações → Páginas, insira o domínio no campo de domínio personalizado. O GitHub criará um arquivo CNAME com este domínio no repositório, ele não poderá ser excluído.
  3. Configure o DNS no registrador. O domínio raiz A-grava aos endereços IP das páginas do GitHub na documentação do GitHub e, para www, defina uma entrada CNAME para o username.github.io.
  4. Aguarde a atualização do DNS. Isso geralmente leva de alguns minutos a um dia.

Etapa 3. HTTPS

Assim que o DNS funcionar, o GitHub emitirá o certificado e a caixa de seleção Impor HTTPS aparecerá em Configurações → Páginas. Ligue-o. Sem HTTPS, os navegadores marcam o site como inseguros, e as transmissões e formulários integrados podem não ser carregados. A marca de verificação inativa significa que o DNS ainda não foi atualizado ou que as entradas foram configuradas com um erro.

Etapa 4: transmissões e links integrados

Gere o código do widget Stripcash com transmissões no gabinete de Stripcash. Como regra, esta é uma tag iframe, que já tem seu ID do parceiro costurado, e a categoria e o modo de exibição são definidos por parâmetros. Cole o código nas páginas HTML no local onde as transmissões devem ser enviadas.

  • Defina IFRAME 100% de largura e altura adequada e, em seguida, verifique como fica no telefone.
  • Nas páginas das categorias, ative o filtro de transmissão correspondente para que o conteúdo corresponda ao tema.
  • Links de referência externos definem o atributo REL com o valor patrocinado. Então você informa honestamente aos motores de busca que o link é afiliado.

Etapa 5. SEO básico

Título e descrição

Cada página precisa de seu próprio título de até 60 a 65 caracteres com uma frase-chave no início e sua própria descrição de 120 a 160 caracteres. O mesmo título em páginas diferentes é usado como duplicatas.

Texto exclusivo

A página onde há apenas iframe está vazia para o mecanismo de pesquisa. Escreva textos que respondam a perguntas reais: como usar o serviço, como as categorias diferem, como manter a privacidade. É impossível multiplicar um artigo alterando a palavra-chave, de modo que o site estará rapidamente sob o filtro. Esta armadilha é descrita com mais detalhes na análise Erros de novato.

Sitemap e Robots.txt

Crie um arquivo sitemap.xml com uma lista de todas as páginas e datas de atualização e especifique o caminho para ele Robots.txt. O gerador ou script de montagem pode fazê-lo automaticamente.

Search Console e Webmaster Yandex

Adicione o site ao Google Search Console e ao Yandex Webmaster. A maneira mais fácil é confirmar a metatag na cabeça da página principal ou um registro TXT no DNS. Em seguida, envie um mapa do site e siga os relatórios de indexação e erros.

Etapa 6. Marcação por idade

Um site sobre um serviço para adultos deve informar isso claramente. Adicione ao head de cada página uma metatag rating com o valor adult, usada pela busca segura e pelos filtros de controle parental. No rodapé ou na primeira tela, inclua um aviso 18+ e explique que o site não é um recurso oficial do Stripchat. Isso protege menores de idade e reduz o risco de penalizações pelos mecanismos de busca.

O que vem a seguir

Após o lançamento, o trabalho está apenas começando. Nas primeiras semanas, os mecanismos de pesquisa olham atentamente para o site e quase não haverá tráfego. Adicione páginas úteis regularmente, corrija bugs de relatórios do webmaster e veja estatísticas no escritório Stripcash Com quebra de etiquetas. Perguntas frequentes

Quanto custa um site no GitHub Pages?

A hospedagem do GitHub Pages é gratuita para repositórios públicos. Você só precisa pagar por um domínio próprio, se quiser usá-lo.

Posso conectar um domínio próprio ao GitHub Pages?

Sim. Informe o domínio nas configurações do Pages. Um arquivo CNAME aparece no repositório, e você configura no registrador os registros DNS que apontam para os servidores do GitHub.

O site terá HTTPS?

Sim. Assim que os registros DNS estiverem funcionando, o GitHub emitirá o certificado. Depois, ative a opção de exigir HTTPS nas configurações.

O GitHub permite sites sobre temas 18+?

As regras de uso aceitável do GitHub restringem conteúdo explícito. Leia-as antes de lançar o site e publique apenas textos e transmissões no modo seguro, sem prévias explícitas.
