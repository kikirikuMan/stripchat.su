Restrições de Navegação Gratuita

Você pode assistir gratuitamente, mas essa visualização tem alguns limites. Nas salas populares, a mensagem gratuita do usuário é facilmente perdida: as gorjetas no bate-papo são destacadas e o texto simples não é destacado. Alguns modelos também fecham o bate-papo para usuários sem tokens para cortar spam.

Também existe um modo de convidado. Sem uma conta, você é completamente anônimo, mas não poderá escrever no chat e salvar os modelos. Leia mais sobre as possibilidades do convidado no guia sobre a visualização sem registrar.

Perguntas frequentes

Por quanto tempo posso assistir gratuitamente?

Por quanto tempo quiser. Algumas funções podem ser limitadas para visitantes, mas não é necessário pagar para assistir às transmissões públicas.

Há cobranças ocultas ao assistir gratuitamente?

Não há cobranças ocultas. O dinheiro só é debitado quando você decide comprar tokens. Sem adicionar saldo, não é possível gastar.

Posso assistir a um show privado gratuitamente?

Shows privados e exclusivos sempre são pagos com tokens. As transmissões públicas são gratuitas, inclusive os shows financiados pelas gorjetas de outros espectadores.
