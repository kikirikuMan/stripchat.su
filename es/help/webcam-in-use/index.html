Cámara en uso por otra aplicación: qué comprobar

Una cámara puede funcionar en una aplicación y negarse a abrirse en otra. Para investigar un conflicto, deja abierta una sola aplicación que la utilice. Un error de lectura del dispositivo es una pista, no una prueba de que otra aplicación lo haya bloqueado.

En esta página

  1. Anota el síntoma antes de cerrar aplicaciones
  2. Deja una sola aplicación usando la cámara
  3. Si el error continúa con las demás aplicaciones cerradas
  4. Obtén un resultado que puedas repetir

Anota el síntoma antes de cerrar aplicaciones

Anota qué aplicación funciona, cuál falla y el mensaje exacto. Un permiso denegado, una cámara ausente y un fallo al abrir una cámara detectada requieren comprobaciones distintas. No cambies varios permisos solo porque una aplicación indique que la cámara está ocupada.

Si estás en una reunión, guarda tu trabajo y sal de ella antes de hacer pruebas. Cerrar una aplicación que utiliza la cámara interrumpirá su vídeo.

Deja una sola aplicación usando la cámara

Si el nuevo intento funciona, has encontrado una solución práctica. Eso no demuestra que todas las cámaras o sistemas operativos impidan el acceso simultáneo.

  1. Detén las vistas previas de otras pestañas, aplicaciones de reuniones y utilidades de configuración de la cámara.
  2. Cierra esas aplicaciones de forma normal. Revisa el área de notificación o la barra de menús: alguna utilidad puede seguir ejecutándose después de cerrar su ventana.
  3. Recarga la página que falla y prueba la cámara una vez. Si funciona, detén la prueba antes de volver a abrir otra aplicación.
  4. Abre las demás aplicaciones una a una y repite la comprobación para identificar cuándo reaparece el conflicto.

Si el error continúa con las demás aplicaciones cerradas

Prueba la aplicación de cámara del sistema por separado; después ciérrala y vuelve al navegador. Si solo falla el navegador, revisa la cámara seleccionada y sus permisos. Si fallan ambos, comprueba la conexión USB o el interruptor físico antes de reinstalar nada.

El error NotReadableError del navegador también puede indicar un problema del sistema operativo o del hardware. Conserva el mensaje como observación, sin tratarlo como una causa ya confirmada.

Obtén un resultado que puedas repetir

Si no está claro qué mantiene ocupada la cámara, guarda tu trabajo, reinicia el ordenador y abre únicamente la aplicación que necesitas. Compara ese inicio con el resultado anterior.

En un equipo administrado, comunica al soporte el modelo de cámara, la aplicación que falla, el error y el resultado de probar una sola aplicación. Evita desactivar protecciones o terminar repetidamente procesos del sistema que no conoces.
