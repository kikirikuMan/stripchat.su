Cómo encender la webcam y detener su uso

La tapa, los ajustes del dispositivo y el permiso de un sitio cumplen funciones diferentes. Usa el control que corresponde a tu objetivo: mostrar imagen ahora, detener la sesión actual o impedir que una aplicación acceda después.

En esta página

  1. Identifica el control físico
  2. Inicia una sola sesión de forma deliberada
  3. Detén la sesión y comprueba el resultado
  4. Decide qué accesos deben seguir permitidos

Identifica el control físico

Algunas cámaras tienen una tapa deslizante; algunos portátiles, una tecla o un interruptor de cámara. La tapa puede limitarse a cubrir la lente, mientras que el interruptor puede desconectar el dispositivo. Consulta el manual en vez de suponer que el indicador luminoso significa lo mismo en todos los modelos.

Abre la tapa cuando estés preparado para comprobar la imagen. Una lente descubierta no concede permiso a una web ni inicia por sí sola la prueba de este sitio.

Inicia una sola sesión de forma deliberada

  1. Comprueba que el sistema operativo permite a la aplicación elegida utilizar la cámara.
  2. Abre la prueba y pulsa Iniciar cámara. Responde a la solicitud de permiso del navegador para este sitio.
  3. Mueve una mano para confirmar que la imagen está en directo. Si procede de otra cámara, revisa la fuente seleccionada.

Detén la sesión y comprueba el resultado

Pulsa Detener en la prueba de este sitio. La vista previa se vacía y se liberan las pistas multimedia. La prueba también se detiene al ocultar la pestaña. Otra aplicación puede seguir usando esa cámara u otra; si permanece un indicador encendido, revisa las demás vistas previas abiertas.

En otra aplicación, utiliza sus propios controles de cámara y consulta su comportamiento documentado. Cerrar una ventana puede dejar la aplicación ejecutándose en segundo plano. Guarda tu trabajo antes de salir de ella por completo.

Decide qué accesos deben seguir permitidos

Retirar el permiso de cámara de un sitio controla sus futuras solicitudes; es distinto de desactivar todo el dispositivo. Usa los ajustes del navegador para una web concreta y la privacidad del sistema para controlar el acceso de aplicaciones.

Si desactivas la cámara en todo el sistema, anota cómo volver a activarla antes de la próxima llamada. En equipos administrados, un administrador puede controlar estos ajustes. Solicita el acceso necesario para la aplicación concreta, sin eludir sus controles.

Privacidad

La prueba empieza al pulsar el botón y autorizar el acceso. Esta herramienta procesa el vídeo o el audio en tu navegador: no los graba ni los envía a un servidor. El alojamiento recibe las solicitudes HTTP habituales necesarias para cargar la página.
