Dónde revisar los permisos de cámara y micrófono

El permiso de una página y el permiso del sistema operativo son controles distintos. Autorizar una web no resuelve un bloqueo del navegador a nivel del sistema; revisa los dos niveles antes de reinstalar la cámara.

En esta página

  1. Empieza por el sitio que estás usando
  2. Comprueba el acceso del navegador en el sistema
  3. Distingue un bloqueo de una solicitud pendiente
  4. Retira el acceso cuando ya no lo necesites

Empieza por el sitio que estás usando

Abre los controles de información o permisos junto a la dirección del navegador. Busca cámara o micrófono y comprueba si el sitio tiene una decisión guardada. Cambia solo el permiso que necesitas para la prueba.

Si elegiste bloquear por error, corrige esa decisión y vuelve a cargar la página antes de repetir la prueba. Evita conceder acceso general a todas las páginas para resolver el problema de una sola.

Comprueba el acceso del navegador en el sistema

En Windows, revisa la sección de privacidad de cámara o micrófono y el acceso de las aplicaciones de escritorio cuando corresponda. En macOS, revisa Cámara o Micrófono dentro de Privacidad y seguridad.

Si el sistema pide cerrar y volver a abrir el navegador para aplicar un cambio, sigue esa indicación. Guarda antes cualquier trabajo pendiente. El nombre exacto de los menús depende del sistema y de su idioma.

Distingue un bloqueo de una solicitud pendiente

Una ventana de permiso sin responder deja la prueba esperando. Busca el aviso del navegador antes de pulsar repetidamente el botón. Si no aparece ninguno, comprueba que has abierto la página mediante HTTPS.

En equipos gestionados por una empresa o un centro educativo, algunas opciones pueden estar fijadas por el administrador. Cuando un control no se puede modificar, facilita el mensaje recibido al soporte del equipo.

Retira el acceso cuando ya no lo necesites

Detener la prueba termina el uso actual del dispositivo por esta herramienta; retirar el permiso del sitio modifica la autorización para futuros accesos. Son acciones diferentes y puedes realizar ambas.

Comprueba por separado cámara y micrófono. Para una vista previa silenciosa solo hace falta la cámara. Si el dispositivo sigue activo tras cerrar la prueba, revisa otras pestañas y aplicaciones abiertas antes de atribuirlo a esta página.

Privacidad

La prueba empieza al pulsar el botón y autorizar el acceso. Esta herramienta procesa el vídeo o el audio en tu navegador: no los graba ni los envía a un servidor. El alojamiento recibe las solicitudes HTTP habituales necesarias para cargar la página.
