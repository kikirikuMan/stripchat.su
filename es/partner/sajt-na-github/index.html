¿Por qué el sitio estático y las páginas de github

El sitio en las páginas de GitHub es más barato si recién comienza a trabajar con su pareja. El alojamiento es gratuito, el servidor no necesita administrarse y las páginas se cargan rápidamente, ya que se trata de archivos HTML ordinarios. Este sitio se organiza de la misma manera: el script recopila textos, menús y metaetiquetas en páginas estáticas, y las transmisiones en vivo se cargan a través del iFrame desde las herramientas de promoción de Stripcash.

El sitio estático no tiene una base de datos, cuentas personales y comentarios, él mismo no sabe nada. Para un proyecto de afiliado, esto es más una ventaja. No hay nada que romper y hackear allí, y toda la atención se destina al texto útil. Puede leer sobre otros formatos de promoción en el artículo sobre Herramientas de socios.

Antes de iniciar, lea las reglas para el uso válido de GitHub. Limitan el contenido franco, por lo que solo colocan texto en dicho sitio, y las transmisiones están incrustadas en modo seguro sin vistas previas francas. No te olvides de las leyes de tu país.

Paso 1. Repositorio y publicación

  1. Registre una cuenta en GitHub y cree un repositorio público.
  2. Ponga el archivo index.html en la raíz. Para cada página siguiente, inicie una carpeta separada con index.html dentro, luego las direcciones resultarán ser ordenadas, como /razdel/stranica/.
  3. Abra Configuración → Páginas y seleccione la rama de origen (generalmente principal) y la carpeta raíz.
  4. Después de uno o dos minutos, el sitio se abrirá en la dirección del nombre de usuario.github.io/nombre del repositorio.

Cuando hay más de una docena de páginas, prescribir el encabezado y el menú en cada mano es aburrido. Es más conveniente almacenar textos por separado y ensamblar el sitio con un pequeño script o generador de sitios estáticos. La salida aún obtendrá un conjunto de archivos HTML.

Paso 2. Dominio propio y cname

En el subdominio de GitHub.io, el sitio se está ejecutando, pero es mejor que un proyecto asociado tenga su propio dominio. Es más fácil de recordar, y no está vinculado al nombre de la cuenta.

  1. Compre un dominio de cualquier registrador. Es mejor no usar las marcas de otras personas en el nombre si no entiende los riesgos.
  2. En Configuración → Páginas, ingrese el dominio en el campo Dominio personalizado. GitHub creará un archivo CNAME con este dominio en el repositorio, no se puede eliminar.
  3. Configure DNS en el registrador. El dominio raíz A-registra a las direcciones IP de las páginas de GitHub desde la documentación de GitHub y, para www, establezca una entrada CNAME en el nombre de usuario.github.io.
  4. Espere la actualización de DNS. Esto suele tardar desde unos pocos minutos hasta un día.

Paso 3. https

Tan pronto como el DNS funcione, GitHub emitirá el certificado en sí y la casilla de verificación Enforce HTTPS en Configuración → Páginas. Enciéndelo. Sin HTTPS, los navegadores marcan el sitio como inseguro, y es posible que las transmisiones y los formularios no se carguen. La marca de verificación inactiva significa que el DNS aún no se ha actualizado o que las entradas están configuradas con un error.

Paso 4: Transmisiones y enlaces integrados

Genere el código del widget StripCash con transmisiones en el gabinete de Stripcash. Como regla general, esta es una etiqueta iframe, que ya tiene cosido su ID de socio, y la categoría y el modo de visualización se establecen por parámetros. Pegue el código en las páginas HTML en el lugar donde deberían ir las transmisiones.

  • Establezca el 100% de ancho y altura adecuadas, luego verifique cómo se ve en el teléfono.
  • En las páginas de categorías, encienda el filtro de difusión correspondiente para que el contenido coincida con el tema.
  • Los enlaces de referencia externos establecen el atributo rel con el valor patrocinado. Por lo tanto, informa honestamente a los motores de búsqueda que el enlace es afiliado.

Paso 5. SEO básico

Título y descripción

Cada página necesita su propio título de hasta 60 a 65 caracteres con una frase clave al principio y su propia descripción de 120 a 160 caracteres. El mismo título en diferentes páginas se toma como duplicados.

Texto único

La página donde solo hay iframe está vacía para el motor de búsqueda. Escriba textos que respondan preguntas reales: cómo usar el servicio, cómo difieren las categorías, cómo mantener la privacidad. Es imposible multiplicar un artículo cambiando la palabra clave, por lo que el sitio estará rápidamente debajo del filtro. Esta trampa se describe con más detalle en el análisis Errores de novatos.

Sitemap y robots.txt

Crear un archivo sitemap.xml con una lista de todas las páginas y fechas de actualización y especificar la ruta a él en robots.txt. El generador o el script de ensamblaje pueden hacerlo automáticamente.

Consola de búsqueda y webmaster de Yandex

Agregue el sitio a Google Search Console y Yandex Webmaster. La forma más fácil es confirmar la metaetiqueta en el encabezado de la página principal o un registro de txt en el DNS. Luego envíe el mapa del sitio y siga los informes de indexación y error.

Paso 6. Clasificación por edades

Un sitio sobre servicios para adultos debe indicarlo con claridad. Añade en el head de cada página una metaetiqueta rating con el valor adult, utilizada por la búsqueda segura y los filtros parentales. Incluye en el pie de página o en la primera pantalla una advertencia 18+ y una aclaración de que el sitio no es un recurso oficial de Stripchat. Así proteges a los menores y reduces el riesgo de sanciones de los buscadores.

¿Qué sigue?

Después del lanzamiento, el trabajo apenas comienza. En las primeras semanas, los motores de búsqueda miran de cerca el sitio y casi no habrá tráfico. Agregue páginas útiles regularmente, corrija errores de informes de webmasters y vea estadísticas en la oficina Stripcash Con desglose de etiquetas. Si quieres acelerar, conecta a otros Fuentes de tráfico y siguen sus reglas.

Preguntas frecuentes

¿Cuánto cuesta un sitio en las páginas de GitHub?

Para los repositorios públicos, GitHub Pages Hosting es gratuito. Solo tendrás que pagar por tu propio dominio si lo necesitas.

¿Puedo conectar mi dominio a las páginas de GitHub?

posible. El dominio encaja en la configuración de páginas, el archivo CNAME aparece en el repositorio y el registrador configura registros DNS que conducen a servidores GitHub.

¿El sitio tendrá https?

voluntad Tan pronto como funcionen los registros de DNS, GitHub emitirá el certificado en sí y quedará por incluir HTTPS forzado en la configuración.

¿Permite GitHub sitios sobre temática 18+?

El uso aceptable de GitHub de GitHub limita el contenido explícito. Léalos antes del lanzamiento y publique solo texto y transmisiones en modo seguro, sin vistas previas explícitas.
