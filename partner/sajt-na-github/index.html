Бесплатный партнёрский сайт на GitHub Pages

Почему статический сайт и GitHub Pages

Сайт на GitHub Pages — самый дешёвый способ начать работу с партнёркой: хостинг бесплатный, сервер администрировать не нужно, а скорость загрузки высокая, потому что страницы — обычные HTML-файлы. Этот сайт устроен именно так: тексты, меню и метатеги собираются скриптом в статические страницы, а живые трансляции подгружаются через iframe из промоинструментов Stripcash.

Статический сайт не умеет ничего «сам»: нет базы данных, личных кабинетов, комментариев. Для партнёрского проекта это плюс. Ломаться нечему, взламывать нечего, а всё внимание уходит на то, что действительно важно, — на полезный текст. О других форматах промо можно почитать в статье про инструменты партнёра.

Перед запуском прочитайте правила допустимого использования GitHub. Они ограничивают откровенный контент, поэтому на таком сайте размещают только текст, а трансляции встраивают в безопасном режиме без откровенных превью. Следите и за законами вашей страны.

Шаг 1. Репозиторий и публикация

  1. Зарегистрируйте аккаунт на GitHub и создайте публичный репозиторий.
  2. Положите в корень файл index.html. Каждая следующая страница — отдельная папка с index.html внутри, тогда адреса будут красивыми, вида /razdel/stranica/.
  3. Откройте Settings → Pages, в качестве источника выберите ветку (обычно main) и корневую папку.
  4. Через минуту-другую сайт откроется по адресу вида имя-пользователя.github.io/имя-репозитория.

Если страниц больше десятка, писать шапку и меню в каждой вручную неудобно. Проще хранить тексты отдельно и собирать сайт небольшим скриптом или генератором статических сайтов. Результат всё равно будет набором HTML-файлов.

Шаг 2. Свой домен и CNAME

Сайт на поддомене github.io работает, но для партнёрского проекта лучше свой домен: его проще запомнить, и он не привязан к названию аккаунта.

  1. Купите домен у любого регистратора. Не используйте в названии чужие торговые марки без понимания рисков.
  2. В Settings → Pages укажите домен в поле Custom domain. GitHub создаст в репозитории файл CNAME с этим доменом. Не удаляйте его.
  3. У регистратора настройте DNS. Для корневого домена — A-записи на IP-адреса GitHub Pages, перечисленные в документации GitHub. Для www — CNAME-запись на имя-пользователя.github.io.
  4. Подождите обновления DNS: обычно от нескольких минут до суток.

Шаг 3. HTTPS

Когда DNS заработает, GitHub автоматически выпустит сертификат. В Settings → Pages появится галочка Enforce HTTPS — включите её. Без HTTPS браузеры помечают сайт как небезопасный, а встроенные трансляции и формы могут не загрузиться. Если галочка неактивна, значит DNS ещё не обновился или записи настроены с ошибкой.

Шаг 4. Встроенные трансляции и ссылки

В кабинете Stripcash сгенерируйте код виджета с трансляциями. Обычно это тег iframe, в адресе которого уже есть ваш партнёрский идентификатор, а параметрами задаются категория и режим отображения. Вставьте его в HTML страницы там, где хотите показать трансляции.

  • Задайте iframe ширину 100% и подходящую высоту, проверьте отображение на телефоне.
  • На страницах категорий используйте соответствующий фильтр трансляций, чтобы контент совпадал с темой.
  • Внешним реферальным ссылкам добавляйте атрибут rel со значением sponsored: так вы честно сообщаете поисковикам, что это партнёрская ссылка.

Шаг 5. Базовое SEO

Title и description

У каждой страницы свой title до 60–65 символов с ключевой фразой в начале и своё описание на 120–160 символов. Одинаковые title на разных страницах поисковики воспринимают как дубли.

Уникальный текст

Страница, на которой только iframe, для поисковика пустая. Пишите тексты, которые отвечают на реальные вопросы: как пользоваться сервисом, чем отличаются категории, как сохранить приватность. Не размножайте одну статью с заменой ключевого слова — это верный путь под фильтр. Подробнее об этой ловушке в разборе ошибок новичков.

Sitemap и robots.txt

Создайте файл sitemap.xml со списком всех страниц и датами обновления, а в robots.txt укажите путь к нему. Генератор или скрипт сборки может делать это автоматически.

Search Console и Яндекс Вебмастер

Добавьте сайт в Google Search Console и Яндекс Вебмастер. Подтвердить права проще всего метатегом в head главной страницы или TXT-записью в DNS. После этого отправьте sitemap и следите за отчётами об индексации и ошибках.

Шаг 6. Возрастная маркировка

Сайт о сервисе для взрослых должен честно об этом сообщать. Добавьте в head каждой страницы метатег rating со значением adult: его учитывают безопасный поиск и родительские фильтры. В подвал или на первый экран поставьте предупреждение 18+ и пояснение, что сайт не официальный ресурс Stripchat. Это защищает несовершеннолетних и снижает риск санкций со стороны поисковиков.

Что дальше

Запуск — только начало. Первые недели поисковики знакомятся с сайтом, и трафика почти не будет. Регулярно добавляйте полезные страницы, исправляйте ошибки из отчётов вебмастеров и смотрите статистику в кабинете Stripcash с разбивкой по меткам. Если захотите ускориться, подключайте другие источники трафика, соблюдая их правила.

Частые вопросы

Сколько стоит сайт на GitHub Pages?

Хостинг GitHub Pages для публичных репозиториев бесплатный. Платить придётся только за собственный домен, если он вам нужен.

Можно ли подключить свой домен к GitHub Pages?

Да. Домен указывается в настройках Pages, в репозитории появляется файл CNAME, а у регистратора домена настраиваются DNS-записи, которые указывают на серверы GitHub.

Будет ли у сайта HTTPS?

Да. После того как DNS-записи начнут работать, GitHub выпускает сертификат автоматически, остаётся включить опцию принудительного HTTPS в настройках.

Разрешает ли GitHub сайты на тему 18+?

У GitHub есть правила допустимого использования, которые ограничивают откровенный контент. Перед запуском прочитайте их и размещайте только текст и трансляции в безопасном режиме без откровенных превью.
