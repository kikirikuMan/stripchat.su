Бесплатный партнёрский сайт на GitHub Pages

Почему статический сайт и GitHub Pages

Сайт на GitHub Pages обходится дешевле всего, если вы только начинаете работать с партнёркой. Хостинг бесплатный, сервер администрировать не нужно, а страницы грузятся быстро, потому что это обычные HTML-файлы. Этот сайт устроен так же: тексты, меню и метатеги скрипт собирает в статические страницы, а живые трансляции подгружаются через iframe из промоинструментов Stripcash.

У статического сайта нет базы данных, личных кабинетов и комментариев, сам он ничего не умеет. Для партнёрского проекта это скорее плюс. Ломаться и взламывать там нечего, и всё внимание достаётся полезному тексту. Про другие форматы промо можно почитать в статье про инструменты партнёра.

Перед запуском прочитайте правила допустимого использования GitHub. Откровенный контент они ограничивают, поэтому на таком сайте размещают только текст, а трансляции встраивают в безопасном режиме без откровенных превью. Не забывайте и о законах своей страны.

Шаг 1. Репозиторий и публикация

  1. Зарегистрируйте аккаунт на GitHub и создайте публичный репозиторий.
  2. Положите в корень файл index.html. Для каждой следующей страницы заводите отдельную папку с index.html внутри, тогда адреса получатся аккуратными, вида /razdel/stranica/.
  3. Откройте Settings → Pages и выберите источником ветку (обычно main) и корневую папку.
  4. Через минуту-другую сайт откроется по адресу вида имя-пользователя.github.io/имя-репозитория.

Когда страниц больше десятка, прописывать шапку и меню в каждой руками надоедает. Удобнее хранить тексты отдельно и собирать сайт небольшим скриптом или генератором статических сайтов. На выходе всё равно получится набор HTML-файлов.

Шаг 2. Свой домен и CNAME

На поддомене github.io сайт работает, но партнёрскому проекту лучше иметь свой домен. Его проще запомнить, и к названию аккаунта он не привязан.

  1. Купите домен у любого регистратора. Чужие торговые марки в названии лучше не использовать, если не понимаете рисков.
  2. В Settings → Pages впишите домен в поле Custom domain. GitHub создаст в репозитории файл CNAME с этим доменом, удалять его нельзя.
  3. Настройте DNS у регистратора. Корневой домен направьте A-записями на IP-адреса GitHub Pages из документации GitHub, а для www заведите CNAME-запись на имя-пользователя.github.io.
  4. Дождитесь обновления DNS. Обычно на это уходит от нескольких минут до суток.

Шаг 3. HTTPS

Как только DNS заработает, GitHub сам выпустит сертификат, и в Settings → Pages появится галочка Enforce HTTPS. Включите её. Без HTTPS браузеры помечают сайт как небезопасный, а встроенные трансляции и формы могут не загрузиться. Неактивная галочка означает, что DNS ещё не обновился или записи настроены с ошибкой.

Шаг 4. Встроенные трансляции и ссылки

Сгенерируйте в кабинете Stripcash код виджета с трансляциями. Как правило, это тег iframe, в адрес которого уже зашит ваш партнёрский идентификатор, а категория и режим отображения задаются параметрами. Вставьте код в HTML страницы в том месте, где должны идти трансляции.

  • Задайте iframe ширину 100% и подходящую высоту, потом проверьте, как он выглядит на телефоне.
  • На страницах категорий включайте соответствующий фильтр трансляций, чтобы контент совпадал с темой.
  • Внешним реферальным ссылкам ставьте атрибут rel со значением sponsored. Так вы честно сообщаете поисковикам, что ссылка партнёрская.

Шаг 5. Базовое SEO

Title и description

Каждой странице нужен свой title длиной до 60–65 символов с ключевой фразой в начале и своё описание на 120–160 символов. Одинаковые title на разных страницах поисковики принимают за дубли.

Уникальный текст

Страница, где есть только iframe, для поисковика пустая. Пишите тексты, отвечающие на реальные вопросы: как пользоваться сервисом, чем отличаются категории, как сохранить приватность. Размножать одну статью, меняя ключевое слово, нельзя, так сайт быстро окажется под фильтром. Эта ловушка подробнее описана в разборе ошибок новичков.

Sitemap и robots.txt

Создайте файл sitemap.xml со списком всех страниц и датами обновления и укажите путь к нему в robots.txt. Генератор или скрипт сборки умеет делать это автоматически.

Search Console и Яндекс Вебмастер

Добавьте сайт в Google Search Console и Яндекс Вебмастер. Права проще всего подтвердить метатегом в head главной страницы или TXT-записью в DNS. Затем отправьте sitemap и следите за отчётами об индексации и ошибках.

Шаг 6. Возрастная маркировка

Сайт о сервисе для взрослых обязан честно об этом говорить. Добавьте в head каждой страницы метатег rating со значением adult, на него смотрят безопасный поиск и родительские фильтры. В подвале или на первом экране разместите предупреждение 18+ и пояснение, что сайт не является официальным ресурсом Stripchat. Так вы защищаете несовершеннолетних и снижаете риск санкций от поисковиков.

Что дальше

После запуска работа только начинается. Первые недели поисковики присматриваются к сайту, и трафика почти не будет. Регулярно добавляйте полезные страницы, исправляйте ошибки из отчётов вебмастеров и смотрите статистику в кабинете Stripcash с разбивкой по меткам. Если захотите ускориться, подключайте другие источники трафика и соблюдайте их правила.

Частые вопросы

Сколько стоит сайт на GitHub Pages?

Для публичных репозиториев хостинг GitHub Pages бесплатный. Платить придётся разве что за собственный домен, если он вам нужен.

Можно ли подключить свой домен к GitHub Pages?

Можно. Домен вписывается в настройках Pages, в репозитории появляется файл CNAME, а у регистратора настраиваются DNS-записи, ведущие на серверы GitHub.

Будет ли у сайта HTTPS?

Будет. Как только DNS-записи заработают, GitHub сам выпустит сертификат, и останется включить в настройках принудительный HTTPS.

Разрешает ли GitHub сайты на тему 18+?

Правила допустимого использования GitHub ограничивают откровенный контент. Прочитайте их до запуска и размещайте только текст и трансляции в безопасном режиме, без откровенных превью.
