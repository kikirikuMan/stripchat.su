# Как писать страницы для stripchat.su

Исходники страниц лежат в `_src/pages/`, готовый сайт собирается командой `node _build/build.mjs` (из корня репозитория). Шапку, подвал, iframe, хлебные крошки, блок «Смотрите также», FAQ-разметку, sitemap и метатеги делает сборщик. В файле страницы только метаданные и текст.

## Формат файла

```html
<!--
{
  "title": "Русские девушки в вебкам-чате онлайн — Stripchat",
  "description": "Описание для выдачи, 120–160 символов.",
  "h1": "Русские вебкам-модели онлайн",
  "nav": "Русские девушки",
  "card": "Одна фраза до 90 символов для карточки в списках (необязательно)",
  "type": "WebPage",
  "iframe": "top",
  "tag": "girls",
  "faq": [
    { "q": "Вопрос?", "a": "Ответ одним-тремя предложениями." }
  ]
}
-->
<section aria-labelledby="intro">
  <h2 id="intro">...</h2>
  <p>...</p>
</section>
```

Поля:
- `title` — до 65 символов, ключевая фраза в начале. У всех страниц разный.
- `description` — 120–160 символов, живое описание с призывом. У всех разное.
- `h1` — заголовок страницы, не копия title.
- `nav` — 1–3 слова: подпись в меню, крошках и карточках. Не менять, если уже задан в заглушке.
- `card` — короткое описание для карточки в списках, если description слишком длинный.
- `type` — `WebPage` для категорий и хабов, `Article` для гидов и статей.
- `iframe` — только раздел зрителей: `top` (трансляции на первом экране, для категорий) или `bottom` (сначала текст, трансляции после него, для гидов). В разделах model и partner не указывать.
- `tag` — категория трансляций в iframe. Работают только `girls`, `couples`, `men`, `trans`. Для всех остальных тем `girls`.
- `faq` — 3–5 вопросов, которые реально ищут, ответы своими словами. Не повторять вопросы других страниц дословно.
- `streamTitle` (необязательно, для `iframe: "bottom"`) — заголовок над трансляциями.
- `ctaTitle`, `ctaText` (необязательно, model и partner) — текст финального блока с кнопкой регистрации.
- `listTitle` (необязательно, хабы `index.html`) — заголовок автоматического списка страниц раздела.

## Тело страницы

- Только `<section>` с `<h2>` внутри, без `<h1>` (его ставит сборщик). Подзаголовки `<h3>`.
- Разрешённая разметка: `p`, `p class="lead"` (первый абзац), `ul`, `ol class="steps"`, `ul class="features"` с `<li><h3>…</h3><p>…</p></li>`, `div class="note"`, `table`, `strong`, `em`, `a`.
- `{{cta}}` — место для кнопки раздела (у зрителей «Смотреть трансляции», у моделей регистрация моделью, у партнёров регистрация в Stripcash). Ставьте 1–2 раза на странице.
- Ссылки только внутренние, абсолютным путём со слешем на конце: `<a href="/gid/tokeny/">`. Внешних ссылок в тексте нет, реферальные ссылки подставляет `{{cta}}`. Сборщик проверяет, что каждая ссылка ведёт на существующую страницу.
- 2–5 внутренних ссылок на страницу, в тексте, по смыслу.
- Объём 600–1000 слов (хабы 300–500). Без стилей, скриптов и картинок.

## Разделы не пересекаются

- `model/*` ни словом и ни ссылкой не упоминает партнёрскую программу, Stripcash, заработок на трафике и ссылки `/partner/`.
- `partner/*` не зовёт в модели и не ссылается на `/model/`.
- Страницы зрителей могут ссылаться на `/model/` и `/partner/` (блок рекламы добавляется автоматически, писать его не нужно).

## Правила текста

- Русский язык, живой и конкретный, на «вы». Каждая страница уникальна: свой угол, свои примеры, своя структура. Нельзя брать соседнюю страницу и менять ключевое слово, поисковики считают такое дорвеем.
- Без переспама: ключевая фраза в title, h1, первом абзаце и пару раз по тексту, дальше синонимы.
- Тон приличный, без откровенных описаний. Это витрина, а не эротический рассказ.
- Все модели и зрители — строго 18+. Никаких слов про школьниц, «молоденьких», «юных», teen и т. п.
- Сайт не официальный сайт Stripchat. Не писать «наш сервис», «наши модели», «мы платим». Stripchat.su — независимый партнёрский сайт.
- Без выдуманных фактов и цифр: никаких конкретных сумм дохода, процентов отчислений, курсов токенов, цен, сроков выплат, количества моделей, если вы не уверены на 100%. Пишите «условия указаны в личном кабинете», «зависит от…».
- Про заработок честно: доход не гарантирован и зависит от усилий. Никаких «лёгких денег» и «пассивного дохода без вложений».
- Не советовать VPN, обход блокировок, обход правил площадок, спам, накрутку, мотивированный трафик.
- Модели: только с 18 лет и с подтверждением документами; добровольность; безопасность и приватность.
