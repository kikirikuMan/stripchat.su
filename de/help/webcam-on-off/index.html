So schaltest du deine Webcam ein und beendest den Zugriff

Eine Abdeckung, eine Geräteeinstellung und die Websiteberechtigung erfüllen unterschiedliche Aufgaben. Wähle den passenden Schalter für dein Ziel: jetzt ein Bild anzeigen, die aktuelle Sitzung beenden oder einer bestimmten Anwendung den späteren Kamerazugriff entziehen.

Auf dieser Seite

  1. Prüfe die physische Bedienung
  2. Starte bewusst eine einzelne Sitzung
  3. Beende die Sitzung und prüfe das Ergebnis
  4. Entscheide über künftige Berechtigungen

Prüfe die physische Bedienung

Manche Kameras besitzen eine verschiebbare Abdeckung, manche Laptops eine Kamerataste oder einen Hardwareschalter. Eine Abdeckung kann nur das Objektiv verdecken, während ein Schalter das Gerät möglicherweise trennt. Prüfe das Gerätehandbuch, statt bei jedem Modell dieselbe Bedeutung der Anzeigeleuchte anzunehmen.

Öffne eine Abdeckung erst, wenn du das Bild prüfen möchtest. Ein freies Objektiv erteilt einer Website noch keine Berechtigung und startet auch nicht den Test dieser Website.

Starte bewusst eine einzelne Sitzung

  1. Vergewissere dich, dass das Betriebssystem der vorgesehenen Anwendung den Kamerazugriff erlaubt.
  2. Öffne den Kameratest und klicke auf Kamera starten. Beantworte die Berechtigungsanfrage des Browsers für diese Website.
  3. Bewege eine Hand im Bild, um eine laufende Vorschau zu bestätigen. Prüfe die ausgewählte Quelle, falls das Bild von einer anderen Kamera kommt.

Beende die Sitzung und prüfe das Ergebnis

Klicke im Test dieser Website auf Stoppen. Die Vorschau wird geleert und die verwendeten Medienspuren werden freigegeben. Dieser Test endet auch, wenn der Tab ausgeblendet wird. Eine andere Anwendung kann weiterhin dieselbe oder eine andere Kamera verwenden. Kontrolliere daher weitere offene Vorschauen, wenn eine Anzeigeleuchte eingeschaltet bleibt.

Verwende in einer anderen Anwendung deren Kamerasteuerung und prüfe das dokumentierte Verhalten. Nach dem Schließen eines Fensters kann eine Anwendung im Hintergrund weiterlaufen. Sichere deine Arbeit, bevor du sie vollständig beendest.

Entscheide über künftige Berechtigungen

Der Entzug einer Websiteberechtigung steuert künftige Anfragen dieser Website. Das ist etwas anderes als das Deaktivieren des gesamten Geräts. Verwende für eine einzelne Website die Websiteeinstellungen des Browsers und für den Anwendungszugriff die Datenschutzeinstellungen des Betriebssystems.

Wenn du die Kamera systemweit deaktivierst, notiere, wie du sie vor dem nächsten Anruf wieder einschaltest. Auf einem verwalteten Computer können diese Einstellungen durch einen Administrator vorgegeben sein. Umgehe die Vorgaben nicht, sondern bitte um den Zugriff für die konkrete Anwendung.

Datenschutz

Der Test beginnt nach einem Klick auf die Startschaltfläche und deiner Zugriffsfreigabe. Dieses Werkzeug verarbeitet Video oder Audio im Browser, ohne es aufzuzeichnen oder an einen Server zu übertragen. Der Hostinganbieter erhält die üblichen HTTP-Anfragen zum Laden der Seite.
