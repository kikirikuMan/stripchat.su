Kamera wird von einer anderen App verwendet: Was tun?

Eine Kamera kann in einer Anwendung funktionieren und sich in einer anderen nicht öffnen lassen. Prüfe einen möglichen Konflikt, indem du jeweils nur eine Kameraanwendung offen lässt. Eine Meldung, dass das Gerät nicht gelesen werden konnte, ist ein Hinweis, aber noch kein Beweis für eine belegte Kamera.

Auf dieser Seite

  1. Notiere den Fehler, bevor du Anwendungen schließt
  2. Lass nur eine Anwendung auf die Kamera zugreifen
  3. Wenn der Fehler auch ohne andere Anwendungen bleibt
  4. Halte ein wiederholbares Ergebnis fest

Notiere den Fehler, bevor du Anwendungen schließt

Notiere, welche Anwendung funktioniert, welche scheitert und wie die Fehlermeldung genau lautet. Ein verweigerter Zugriff, eine fehlende Kamera und ein fehlgeschlagener Zugriff auf eine aufgelistete Kamera erfordern unterschiedliche Prüfungen. Ändere nicht mehrere Berechtigungen, nur weil eine Anwendung die Kamera als belegt meldet.

Wenn du gerade an einer Besprechung teilnimmst, sichere deine Arbeit und verlasse sie vor dem Test. Das Schließen einer Kameraanwendung unterbricht deren Video.

Lass nur eine Anwendung auf die Kamera zugreifen

Ein erfolgreicher erneuter Versuch zeigt einen brauchbaren Lösungsweg. Er belegt nicht, dass jede Kamera oder jedes Betriebssystem gleichzeitige Zugriffe grundsätzlich verhindert.

  1. Beende Vorschauen in anderen Browsertabs, Besprechungsprogrammen und Dienstprogrammen zur Kameraeinrichtung.
  2. Schließe diese Anwendungen regulär. Prüfe im Infobereich oder in der Menüleiste, ob ein Dienstprogramm nach dem Schließen seines Fensters weiterläuft.
  3. Lade die betroffene Seite neu und starte die Kamera einmal. Funktioniert sie, beende den Test, bevor du eine andere Anwendung öffnest.
  4. Öffne die anderen Anwendungen einzeln und wiederhole jeweils dieselbe Prüfung. So erkennst du, wann der Konflikt zurückkehrt.

Wenn der Fehler auch ohne andere Anwendungen bleibt

Öffne zunächst nur die Kameraanwendung des Systems. Schließe sie anschließend und teste den Browser erneut. Scheitert nur der Browser, prüfe dort die ausgewählte Kamera und die Berechtigungen. Scheitern beide, kontrolliere USB-Verbindung oder physischen Kameraschalter, bevor du etwas neu installierst.

Ein NotReadableError im Browser kann auch auf ein Problem des Betriebssystems oder der Hardware zurückgehen. Bewahre die Meldung in deinen Notizen auf, statt sie als Bezeichnung einer bereits bestätigten Ursache zu behandeln.

Halte ein wiederholbares Ergebnis fest

Bleibt unklar, welche Anwendung die Kamera belegt, sichere deine Arbeit, starte den Computer neu und öffne ausschließlich die gewünschte Anwendung. Vergleiche diesen frischen Start mit dem vorherigen Ergebnis.

Bei einem verwalteten Computer helfen dem Support das Kameramodell, die betroffene Anwendung, die Fehlermeldung und das Ergebnis des Tests mit nur einer Anwendung. Deaktiviere keine Schutzfunktionen und beende nicht wiederholt unbekannte Systemprozesse.
