Kostenlose Partnerwebsite auf GitHub Pages

Warum ist die statische Site- und GitHub-Seiten

Die Website auf GitHub-Seiten ist billiger, wenn Sie gerade erst anfangen, mit Ihrem Partner zusammenzuarbeiten. Das Hosting ist kostenlos, der Server muss nicht verwaltet werden und die Seiten werden schnell geladen, da es sich um normale HTML-Dateien handelt. Diese Seite ist auf die gleiche Weise angeordnet: Das Skript sammelt Texte, Menüs und Meta-Tags in statische Seiten, und Live-Sendungen werden über den iFrame von den Stripcash-Werbungstools geladen.

Die statische Seite hat keine Datenbank, persönliche Konten und Kommentare, er selbst weiß nichts. Für ein Affiliate-Projekt ist dies eher ein Plus. Dort gibt es nichts zu brechen und zu hacken, und die ganze Aufmerksamkeit geht auf den nützlichen Text. Weitere Promo-Formate finden Sie im Artikel über Partnertools.

Lesen Sie vor dem Start die Regeln für die gültige Verwendung von GitHub. Sie schränken den Frank-Inhalt ein, so dass sie nur Text auf einer solchen Website platzieren, und Sendungen werden im abgesicherten Modus ohne Frank-Vorschau eingebettet. Vergessen Sie nicht die Gesetze Ihres Landes.

Schritt 1. Repository und Publikation

  1. Registrieren Sie ein Konto bei GitHub und erstellen Sie ein öffentliches Repository.
  2. Legen Sie die Datei index.html in den Stamm. Starten Sie für jede nächste Seite einen separaten Ordner mit index.html im Inneren, dann werden die Adressen ordentlich, wie /razdel/stranica/.
  3. Öffnen Sie Einstellungen → Seiten und wählen Sie den Quellzweig (normalerweise Haupt) und den Stammordner aus.
  4. Nach ein oder zwei Minuten öffnet sich die Site unter der Adresse des Benutzernamens.github.io/repository name.

Wenn es mehr als ein Dutzend Seiten gibt, ist es langweilig, den Header und das Menü in jeder Hand zu verschreiben. Es ist bequemer, Texte separat zu speichern und die Website mit einem kleinen Skript oder einem Generator statischer Sites zusammenzubauen. Die Ausgabe erhält weiterhin eine Reihe von HTML-Dateien.

Schritt 2. Eigene Domäne und CNAME

Auf der Github.io-Subdomain läuft die Site, aber es ist besser, wenn ein Partnerprojekt eine eigene Domain hat. Es ist leichter zu merken und ist nicht an den Namen des Kontos gebunden.

  1. Kaufen Sie eine Domain von jedem Registrar. Es ist besser, die Marken anderer Personen nicht im Namen zu verwenden, wenn Sie die Risiken nicht verstehen.
  2. Geben Sie in Einstellungen → Seiten die Domäne in das Feld Benutzerdefinierte Domäne ein. GitHub erstellt eine CNAME-Datei mit dieser Domäne im Repository, die nicht gelöscht werden kann.
  3. Konfigurieren Sie DNS beim Registrar. Root-Domain-A-Records auf GitHub-Seiten-IP-Adressen aus der GitHub-Dokumentation, und für www setzen Sie einen CNAME-Eintrag auf den Benutzernamen.github.io.
  4. Warten Sie auf das DNS-Update. Dies dauert in der Regel von einigen Minuten bis zu einem Tag.

Schritt 3. HTTPS

Sobald das DNS funktioniert, stellt GitHub das Zertifikat selbst aus und das Kontrollkästchen HTTPS erzwingen wird in Einstellungen → Seiten angezeigt. Schalten Sie es ein. Ohne HTTPS markieren Browser die Website als unsicher, und integrierte Broadcasts und Formulare können nicht geladen werden. Das inaktive Häkchen bedeutet, dass das DNS noch nicht aktualisiert wurde oder die Einträge fehlerhaft konfiguriert sind.

Schritt 4: Eingebaute Sendungen und Links

Generieren Sie den Stripcash-Widget-Code mit Sendungen im Stripcash-Schrank. In der Regel handelt es sich hierbei um ein iFrame-Tag, bei dem bereits Ihre Partner-ID aufgenäht wurde, und die Kategorie und der Anzeigemodus werden durch Parameter festgelegt. Fügen Sie den Code in die HTML-Seiten an der Stelle ein, an die die Sendungen gehen sollten.

  • Stellen Sie den iFrame auf 100% Breite und geeignete Höhe ein und überprüfen Sie dann, wie es auf dem Telefon aussieht.
  • Aktivieren Sie auf den Seiten der Kategorien den entsprechenden Broadcast-Filter, damit der Inhalt dem Thema entspricht.
  • Externe Empfehlungslinks Legen Sie das rel-Attribut mit dem gesponserten Wert fest. So informieren Sie die Suchmaschinen ehrlich, dass der Link Affiliate ist.

Schritt 5. Grundlegende SEO

Titel und Beschreibung

Jede Seite benötigt einen eigenen Titel mit bis zu 60–65 Zeichen mit einem Schlüsselwort am Anfang und einer eigenen Beschreibung von 120–160 Zeichen. Der gleiche Titel auf verschiedenen Seiten wird als Duplikate angesehen.

Eindeutiger Text

Die Seite, auf der nur iFrame für die Suchmaschine leer ist. Schreiben Sie Texte, die echte Fragen beantworten: Wie man den Service nutzt, wie sich die Kategorien unterscheiden, wie man den Datenschutz aufrechterhält. Es ist unmöglich, einen Artikel durch Ändern des Schlüsselworts zu multiplizieren, sodass sich die Website schnell unter dem Filter befindet. Diese Falle wird in der Analyse ausführlicher beschrieben Newbie-Fehler.

Sitemap und robots.txt

Erstellen Sie eine Sitemap.xml-Datei mit einer Liste aller Seiten und Aktualisierungsdaten und geben Sie den Pfad zu ihm in an robots.txt. Der Generator oder das Assembly-Skript kann dies automatisch tun.

Search Console und Yandex Webmaster

Fügen Sie die Website zur Google Search Console und zu Yandex Webmaster hinzu. Am einfachsten ist es, das Meta-Tag im Kopf der Hauptseite oder einen TXT-Datensatz im DNS zu bestätigen. Senden Sie dann die Sitemap und folgen Sie den Indexierungs- und Fehlerberichten.

Schritt 6. Altersmarkierung

Eine Website über einen Dienst für Erwachsene muss das deutlich angeben. Ergänze im head jeder Seite ein rating-Metatag mit dem Wert adult. SafeSearch und Jugendschutzfilter berücksichtigen diese Angabe. Platziere im Footer oder im ersten sichtbaren Bereich einen Hinweis ab 18 Jahren und erkläre, dass die Website kein offizielles Angebot von Stripchat ist. Damit schützt du Minderjährige und verringerst das Risiko von Suchmaschinen-Sanktionen.

Was kommt als nächstes?

Nach dem Start beginnt die Arbeit gerade. In den ersten Wochen schauen Suchmaschinen genau auf die Website, und es wird fast keinen Verkehr geben. Fügen Sie regelmäßig nützliche Seiten hinzu, beheben Sie Fehler aus Webmaster-Berichten und sehen Sie sich Statistiken im Büro an Stripcash Mit Etiketten-Panne. Wenn Sie beschleunigen möchten, verbinden Sie andere Verkehrsquellen und befolgen ihre Regeln.

Häufige Fragen

Was kostet eine Website auf GitHub Pages?

Für öffentliche Repositories ist das Hosting bei GitHub Pages kostenlos. Bezahlen musst du gegebenenfalls nur eine eigene Domain.

Kann ich eine eigene Domain mit GitHub Pages verbinden?

Ja. Trage die Domain in den Pages-Einstellungen ein. Im Repository erscheint eine CNAME-Datei, und beim Registrar richtest du DNS-Einträge zu den GitHub-Servern ein.

Bekommt die Website HTTPS?

Ja. Sobald die DNS-Einträge funktionieren, stellt GitHub das Zertifikat aus. Anschließend aktivierst du in den Einstellungen die HTTPS-Erzwingung.

Erlaubt GitHub Websites zu Themen ab 18?

Die GitHub-Regeln zur zulässigen Nutzung schränken explizite Inhalte ein. Lies sie vor dem Start und veröffentliche nur Texte und Streams im sicheren Modus ohne explizite Vorschaubilder.
